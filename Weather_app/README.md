# Weather App

A simple weather application built using HTML, CSS, and JavaScript. It fetches and displays weather information for a selected location using a weather API.

## Features

- Search for weather by location
- Displays current weather information
- Shows temperature and weather conditions
- Fetches real-time data from a weather API
- Simple and responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## Purpose

This project was created as a practice project while learning JavaScript, APIs, asynchronous programming, and DOM manipulation.
