# Time & Stopwatch

A simple time application built using HTML, CSS, and JavaScript. It displays the current time and includes a stopwatch with start, pause, and reset controls.

## Features

- Displays the current time
- Live updating clock
- Stopwatch with hours, minutes, seconds, and milliseconds
- Start, pause, and reset controls
- Responsive and minimal interface
- Glassmorphism-style UI

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

This project was created as a small practice project while learning JavaScript, working with time-related functions, DOM manipulation, and event handling.
